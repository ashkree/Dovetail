## v1.1, in order

1. **Research** — *(built through reading mode and tangents, M22; parallel rounds left)* first, because the user needs it for their job now. Capture every research subagent's full output and the sources it actually read; rounds with a `brief.md`; a cited `report.md` the coordinator rewrites each round; ideas and decisions as inbox proposals with evidence; reading mode (`<leader>r`); tangents in a global space. Spec, ADRs 0015–0018, conflicts and a session schedule come from the overnight docs task (branch `docs/research-feature`, `docs/research.md`, `docs/plan/research-sessions.md`). Its key-binding conflicts (`<leader>b` is the board) need your call before the UI half starts.
2. **Tool suites and claims** — *(suites and renames built, PR #55; claims left)* suite prefixes on tool names, role config lists suites (ADR 0016); `claim` / `release` / `list_claims` fill the Coordination suite (decision 25). Done together so the rename happens once.
3. **Task notes** — one markdown file per task (`tasks/<id>.md`), edited by handing off to nvim, shown in the task detail (decision 19). Research reports link from the task the same way.
4. **Search** — FTS5 over notes, decisions, journal, messages, inbox, conversation text and research files; `<leader>/` picker; deep transcript search on demand (decision 20).
5. **Daily review cycle** — the morning review buffer and `:morning` on top of ADR 0012; new tangents are filed, started or dropped there (decision 17, research decision 8); until then the "N new tangents" Needs-you item and `:tangents` do it (built, M22).
6. **Fresh starts with handoffs** — *(`:fresh` built, PR #57; the automatic 80 % trigger and slices' restarts left)* above 80 % context the coordinator is offered a fresh start with a handoff and slices restart on their own (decision 22), reusing ADR 0012's handoff.
7. **Side-chat helper and side panel** — *(side panel built, PR #52; tangents in it built, M22; grill auto-start left)* grill auto-start into the one side panel (research decision 8).
8. **Configurable keymap** — the keymap table read from TOML, with a which-key popup (decision 10). Late on purpose: the research and side-panel keys settle first.
9. **Maps stage 2** — map comments and Mermaid import (decision 23).
10. **Syntax highlighting and theme config.**
11. **PR ownership tools** (README roadmap).
12. **Dovetail plugin with skills** for procedures (decision 8c's "plugin skills later").
