# M4 review and retro

(Written as M4 is built. The review and retro sections are added when it closes.)

## Decisions needed (with the default used), logged as they were made

1. **`NewTask` gains `pr` (API change, additive).** Quick capture's `#1231` token sets a linked PR, but `NewTask` had no such field, so the capture would have needed a second command after the task exists. Recommend keeping.
2. **Capture link means "follow-up of" (D2).** The link under the line (`linked to: …`, on by default, `Ctrl-l` switches it) sets the new task's `follow_up_of`. The brief says only "linked to". Recommend keeping; the alternative is a dependency.
3. **`a` in the tree opens the same quick capture (D3).** M2's title-only prompt is gone; `a` and `<leader>t` are one overlay, so `a` also takes tokens and links to the task under the cursor.
4. **Overlays use Insert mode (D4).** The picker, switcher and capture show `INSERT` while open, because they take typed text. No fourth mode.
5. **`Tab` in capture (D5).** Saves, then opens the new task's detail as soon as the core announces it (matched by title). With the real core (M5) the id may come back in the command result instead.
6. **Esc and "the same key" go back (D6).** Task detail, Activity and Messages show in the main region; `Esc` returns it to the conversation, and so does pressing `<leader>a` or `<leader>m` again. Focus stays on the main region.
7. **Context fill (D7).** The tree shows `NN%` after a slice's memory (not for subagents or the coordinator); the status bar shows `ctx NN%` for the coordinator. Plain up to 60, amber to 80, red above.
8. **Search (D8).** `/` takes a term on the prompt row; smart case (a capital makes it exact); `n` and `N` step through matching rows of the focused buffer and wrap; one term shared by all buffers; no highlighting of the match yet. Conversation search matches the rendered lines.
9. **Feeds (D9).** Activity and Messages list newest first, one row each; `Enter` opens the agent (the sender for a message). No filtering yet.
10. **New slice (D10).** `<leader>sn` asks for a name, then a brief, on the prompt row; the slice is on the task in focus. `:spawn name brief…` does it in one line. M8 replaces the prompts with its real flow.
11. **Subagents and `sm`/`sx` (D11).** On a subagent both apply to its parent session, with a note (plan B20). `:interrupt <name>` takes any agent's name.
12. **Stubs (D12).** `<leader>st`, `<leader>pp`, `<leader>pr` only say when they arrive (M14, M5).
13. **Picker keys (D13).** Type to filter; `Ctrl-j`/`Ctrl-k` or the arrows move (so `j` and `k` are text); `Enter` opens; `Esc` closes. An empty query lists section headings; a typed one ranks flat. Row age is `now`, `2m`, `3h`, `4d`. An agent's preview shows its latest turns last.
14. **Choosing in the finder (D14).** A task opens its detail, an agent its conversation, an inbox item jumps to it in the inbox.
15. **Task detail (D15).** Title, P-level, bucket, status, PR, follow-up and coordinator-created markers, dependencies, notes, agents. No decision log (v1.1). `e` says notes editing arrives with storage (M5); `s`, `b`, `p` cycle as in the tree.
16. **`:` aliases (D16).** `inbox`, `coordinator`, `alternate`, `activity`, `messages`, `switch`, `find`, `add`/`capture`, `mode`/`perm`, `takeover`, `project`, `register`, `solid`, `spawn`, `interrupt`, `q`, `q!`. Visible names are yours to change.
17. **Keys against the brief (D17).** All of the brief's global keys for M4 are bound: `/ n N`, `<leader><leader>`, `<leader>c`, `<leader><Tab>`, `<leader>n`, `<leader>m`, `<leader>a`, `<leader>ss/sn/st/sx/sm`, `<leader>pp/pr`, `<leader>t`. Not bound, by plan: `<leader>b` and `<leader>g` (M12), `<leader>z` (M16).
18. **Status-bar hints (D18).** The right side now lists `i`, `␣ss`, `␣t`, `/`, `␣n`, `:`; narrow screens show a shorter form.
