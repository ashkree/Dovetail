# Collapse finished turns to one inbox item per agent

Refines Decision 7b, which puts every finished turn in Needs you. Taken literally, a long chat with the coordinator buries permission requests and questions under items for a conversation the user is already reading. So each agent has at most one finished-turn item, with the newest replacing the last; opening the agent clears it, and an agent with background subagents still running adds none, because its first `result` does not mean it has stopped. Permission requests, questions and errors are never collapsed. Older previews stay readable in the conversation. Approved by the user in the session that worked through [implementation plan section 7, item B3](../implementation-plan.md#7-where-the-docs-disagree-or-say-nothing).
